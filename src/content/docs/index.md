title: "CDP Inspector"

---

Get started with [installation](/installation/) or the [quick start](/quick-start/). See [release notes](/release-notes/) for the latest changes.

CDP Inspector is a two-part tool. The **popup** (click the toolbar icon) generates a ready-to-run Chrome launch command with remote debugging enabled, then lists every debuggable tab on that instance - and lets you open new ones. The **inspector panel** (opened by attaching to a tab) connects directly to that tab's CDP WebSocket for a live screencast, a raw CDP command sender, one-click presets for common actions, and a dedicated Network tab that captures HTTP(S) requests and manages custom HTTP headers.

Because every Chrome instance it launches is a throwaway, isolated profile, it also doubles as a sandbox for **AI agents** to drive and debug real applications - see [AI & automation use cases](/workflows/ai-and-automation/) below.
